# 🐕 Mantrailing Ausbildungsheft

> Ein interaktives, mobilfreundliches Ausbildungsformular für Mantrailer-Hundetraining

## 🌐 Live-Version

👉 **[Zur Webseite](https://suchhundejena.github.io/mantrailing-heft/)**

## ✨ Features

✅ **Vollständige Ausbildungsinhalte**
- 🟢 **Anfänger**: Grundlagen, Start-Ritual, erste Schwierigkeiten
- 🔵 **Fortgeschritten**: Streckenlängen, Trailtypen, Indoor-Training
- 🟣 **Experte**: Extreme Herausforderungen, Wettkampf-Training

✅ **Benutzerfreundlichkeit**
- 📱 100% mobiloptimiert (responsive Design)
- 💾 **Lokale Speicherung** - Alle Daten werden im Browser gespeichert
- 🔄 Automatische Speicherung bei jeder Änderung
- ⚡ Schnell und offline nutzbar

✅ **Funktionen**
- ✔️ Übungen abhaken
- 📅 Datumsfeld pro Übung
- 👨‍🏫 Trainer*in-Name dokumentieren
- 📝 Bemerkungsfeld für Notizen
- 📊 Fortschrittsanzeige in %
- 📥 **Export als TXT-Datei** zum Drucken/Archivieren
- 🔄 Daten laden/speichern
- 🗑️ Zurücksetzen

✅ **Design**
- 🎨 Modernes, farbiges Interface
- 🌈 Gradient-Hintergründe
- 📊 Statistik-Karten
- 🎯 Intuitive Navigation

## 🚀 Lokale Installation (optional)

Wenn du die Datei lokal bearbeiten möchtest:

```bash
git clone https://github.com/suchhundejena/mantrailing-heft.git
cd mantrailing-heft

# Mit Python 3 starten:
python -m http.server 8000

# Dann öffnen: http://localhost:8000
```

## 📋 Struktur der Trainingsinhalte

### 1️⃣ **Anfänger** (Basics)
- Grundlagen (Entdeckertrails, Anriechen, Kommandos)
- Start-Ritual (9 Schritte)
- Erste Schwierigkeiten (8 Übungen)
- Streckenlängen (200–500m)
- Kreuzungsarbeit & Leinenhandling

### 2️⃣ **Fortgeschritten** (Intermediate)
- Streckenlängen (500–1500m)
- Streckenverlauf & Formen (9 Formen)
- Umgebung & Gelände (5 Szenarien)
- Kontamination & Spurdifferenzierungen
- Trailtypen (9 Spezialtypen)
- Geruchsartikel, Start-Varianten
- Alte Trails (6–72 Stunden)
- VP-Varianten (7 Variationen)
- Negativ-Training (4 Methoden)
- Indoor-Training (9 Übungen)

### 3️⃣ **Experte** (Advanced)
- Extreme Streckenlängen (1500–3000+m)
- Extreme Altersunterschiede (3 Tage – 1 Woche)
- Spezielle Umgebungen (Wald, Wasser, Berge, Stadt, Industrie)
- Extreme Schwierigkeiten
- Wettkampf-Training (4 Niveaus)

## 💾 Datenspeicherung

**Alle Daten werden lokal im Browser gespeichert** (LocalStorage). Das bedeutet:
- ✅ Keine Daten verlassen deinen Computer
- ✅ Funktioniert offline
- ✅ Schneller Zugriff
- ⚠️ Werden gelöscht, wenn du Browserdaten löschst

## 📥 Export

Du kannst deine Trainings-Daten jederzeit als **TXT-Datei** exportieren:
- Alle Übungen mit Status
- Datum, Trainer*in-Name, Bemerkungen
- Ideal zum Ausdrucken oder Archivieren

## 🎯 Verwendung

1. **Persönliche Daten** ausfüllen (oben)
2. **Kapitel aufklappen** (1️⃣ Anfänger → 2️⃣ Fortgeschritten → 3️⃣ Experte)
3. **Übungen abhaken** ✔️
4. **Datum, Trainer*in, Bemerkungen** eintragen
5. **Speichern** 💾 (läuft automatisch)
6. **Fortschritt** in der Statistik verfolgen 📊
7. **Exportieren** 📥 zum Archivieren
